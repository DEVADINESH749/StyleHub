**# StyleHub – Fashion Mini Store**



**StyleHub is a full-stack fashion e-commerce web application built using FastAPI, SQLite, React, Tailwind CSS, JWT authentication, and Stripe test payments.**



**## Features**



**### Customer**

**- User registration and login**

**- JWT authentication**

**- Browse fashion products**

**- Search products**

**- Filter products by category**

**- Add products to cart**

**- Update cart quantity**

**- Remove products from cart**

**- Create orders**

**- Stripe test-mode payment**

**- View My Orders**

**- Responsive navigation**



**### Admin**

**- Admin authentication**

**- Admin dashboard**

**- View products**

**- Add products**

**- Edit products**

**- Delete products**

**- View customer orders**

**- Manage product information**



**## Technologies Used**



**### Backend**

**- Python**

**- FastAPI**

**- SQLAlchemy**

**- SQLite**

**- JWT Authentication**

**- Password Hashing**

**- Stripe API**



**### Frontend**

**- React**

**- Vite**

**- Tailwind CSS**

**- Axios**

**- Stripe React**
