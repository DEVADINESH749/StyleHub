**# StyleHub – Fashion Mini Store**



**StyleHub is a full-stack fashion e-commerce web application built using FastAPI, SQLite, React, Tailwind CSS, JWT authentication, and Stripe test-mode payments.**



**## Features**



**### Customer**



**- Customer login**

**- JWT authentication**

**- Browse fashion products**

**- Search products**

**- Filter products by category**

**- Add products to cart**

**- Update cart quantity**

**- Remove products from cart**

**- Create orders**

**- Stripe test-mode payment**

**- View My Orders**

**- Responsive navigation**

**- Customer logout**



**### Admin**



**- Admin authentication**

**- Admin dashboard**

**- View products**

**- Add products**

**- Edit products**

**- Delete products**

**- View customer orders**

**- Product management**

**- Order monitoring**

**- Admin logout**

**- Dashboard statistics**



**## Technologies Used**



**### Backend**



**- Python**

**- JWT Authentication**

**- Password Hashing**

**- Stripe API**

**- Stripe Webhooks**



**### Frontend**
